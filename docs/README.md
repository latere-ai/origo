## Changing it

The design, and the reasoning behind each decision, is in
[`specs/`](../specs/README.md). [`CONTRIBUTING.md`](../CONTRIBUTING.md) is
how to build and test a change. [`spikes/`](spikes/) holds the measurements
that settled a design question, kept as engineering records rather than as
documentation.

`configuration.md` and `api.md` are generated by `make docs` from the code
and the specs. Edit the source, not the page.

# Documentation

For people who run Origo, build against it, or change it. Trying it out
before installing it takes one command: see the quick start in the
[README](../README.md#try-it-in-a-few-minutes).

## Running it

Read these in order the first time.

| Page | |
|---|---|
| [Install](install.md) | from a cluster and a bucket to a first push |
| [Configuration](configuration.md) | every environment variable with its default and what reads it |
| [Operations](operations.md) | backup, restore, scaling, repository administration, metrics and alerts, and what to do during an outage |
| [Upgrades](upgrades/README.md) | what a version number promises, how to upgrade and roll back, and how to verify what you install |
| [Migration](migration.md) | moving repositories in from another git host |
| [origo-web](https://github.com/latere-ai/origo-web) | an optional browsing interface, in its own repository |

## Building against it

| Page | |
|---|---|
| [API](api.md) | authentication, addressing, every route with the permission it needs, errors, headers, limits, and push events |
| [Authorization endpoint](authorizer.md) | the endpoint that decides what Origo allows, and the SSH key endpoint, for whoever writes them |
| [The origo command](cli.md) | reading and changing a repository from a shell or an agent, without cloning it |

## Changing it

| Page | |
|---|---|
| [Internals](internals/README.md) | how the code is laid out, how a push and a read move through it, how it is tested, and how a release is cut |
| [`CONTRIBUTING.md`](../CONTRIBUTING.md) | how to build, test, and send a change |
| [`specs/`](../specs/README.md) | the design records: each decision and the reasoning behind it |

`configuration.md` and `internals/contract.md` are generated by
`make docs` from the code and the specs; edit the source, not the page.
[`spikes/`](spikes/) holds the measurements that settled a design
question, kept as engineering records.
